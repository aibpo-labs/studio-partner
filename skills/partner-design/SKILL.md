---

项目根目录是此文件的 `../..`。读 `server/design-client.mjs`、`server/design.mjs`、`design-agent/instructions.md` 与 `examples/workbench/app.js` 中的 Design 交互。

- 在连接配置中填写 Design Agent 服务地址、访问凭证和 Agent 标识；可选指定版本。凭证与 Agent 标识是不同配置项，使用客户指定且已发布的 Design Agent。
- 同一聊天应保持上下文连续，刷新后恢复已有消息与关联的工作区；重复连接或恢复时不要重复显示已收到的内容。
- 需要用户确认的操作必须显示清楚并等待用户决定，不得默认替用户授权。
- 仅展示 Design Agent 为当前对话生成的文件，按服务端提供的文件清单读取；限制文件路径和类型，禁止读取工作区之外的文件。
- 修改已有配置时先读取旧文件，只调整用户提出的内容。生成后校验文件格式；下载文件不代表已应用、验证或发布。
- Design Agent 由使用者在自己的服务中准备并发布，并按 LatenTX Agent Skill 接入说明完成配置。应用不会自动创建或发布 Design Agent。
- Design 只提供聊天、文件/图片输入和工作区。不要添加配置差异或机器人草稿回填。当前适配已包含附件上传、工作区路径引用和输出快照下载；图片理解及可读文件类型取决于所接入服务。附件不会自动成为独立的多模态消息。

验收：一次生成、同会话只修改一个字段、确认其余字段不变、预览和下载、刷新恢复、停止运行。不要增加账号、租户、方案库或机器人配置自动下发，除非用户另有要求。
